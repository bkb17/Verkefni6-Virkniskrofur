## Workflow

Hópurinn hefur uppfært gátreitina í `.github/pull_request_template.md` til að endurspegla gæðaviðmiðin (Atomic, Shall, Verifiable, o.fl.).

Höfundur gerir skref 1-5 og 8. Rýnir gerir skref 6 og 7.

1. Búðu til nýja grein (branch) fyrir hverja kröfu, t.d. `feature/FR-01`
2. Skrifaðu kröfuna í `requirements/FR-01.md` samkvæmt leiðbeiningum.
3. Gerðu commit með lýsandi skilaboðum (t.d. "Endurbætt krafa FR-01: Bætti við skal og gerði mælanlega").
4. Push-a greininni á GitHub.
5. Búðu til Pull Request frá `feature/FR-01` til `main`.
6. **Rýnir** fer yfir kröfuna í Pull Request og fyllir út gátreitinn og skrifar athugasemdir.
7. **Rýnir** uppfærir `reviews/PR-Comments.md` með niðurstöðum.
8. Ef samþykki fæst sameinar **höfundur** greinina við main (merge).
